# Config Server

Serveur de configuration centralisée pour la plateforme **Gestion des événements universitaires** (équipe Warriors).

## Rôle
- Centraliser les fichiers de configuration (`application.yml`) de l'ensemble des microservices et de l'API Gateway.
- Permettre à chaque service de récupérer ses paramètres au démarrage sans dupliquer les configurations entre projets.

## Port
- **8888**
